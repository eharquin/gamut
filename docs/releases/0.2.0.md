# GAMUT 0.2.0 Release Notes

- **Status:** Stable release
- **Tag:** `v0.2.0`
- **Release date:** 2026-11-10
- **Acceptance:** [PGA 2D Foundation Acceptance Record](../acceptance/pga-2d-foundation.md)
  (automated evidence ready; manual and deployed validation pending,
  [#192](https://github.com/eharquin/gamut/issues/192))
- **Changelog:** [0.2.0](../../CHANGELOG.md#020---2026-11-10)

GAMUT 0.2.0 is the first release shipped under the GAMUT name (formerly
MultiVector). It adds the plane-based projective algebra PGA(2) beside VGA(2),
self-contained scene links, a local graph library, and a reworked appearance
and expression workflow, while opening every 0.1.0 document and browser
session unchanged.

## Highlights

- **PGA(2).** The registered algebra `org.multivector.pga` with points, ideal
  points, lines, the line at infinity, translators, motors and reflections;
  `point`, `ipoint` and `line` constructors, `norm` and `inorm`, and the
  logarithm and square root of unit motors. Points, clipped lines, ideal
  points and connected point lists are drawn and dragged in the viewport.
- **Product identity.** The product is renamed **GAMUT — Geometric Algebra
  Multivector Unveiling Tool**; the repository is `eharquin/gamut` and the
  application is served at <https://eharquin.github.io/gamut/>. Downloads use
  `*.gamut.json`; `*.multivector.json` documents still open.
- **Scene sharing.** **Copy link** produces a self-contained, versioned,
  integrity-checked scene link that opens as a temporary session; documents
  also open by dropping their `.json` file on the window.
- **Local graph library.** **Save** and **Library** keep named graphs in the
  browser, grouped by algebra, with New, Open, Rename, Duplicate, Delete and
  Save as new graph; the header shows the graph name and a dot on **Save**
  while changes are unsaved.
- **Language.** Gather indexing `L[I]`, the scalar modulo `%`, and the scalar
  functions `abs`, `sqrt` and their companions, in every algebra.
- **Appearance.** A reworked appearance menu: colors, opacity, stroke and
  point styles, labels and per-row normalization, stored in canonical format
  version 7 (earlier versions migrate on load).
- **Expression panel.** An expression reference docked in the panel with
  **General | VGA** or **General | PGA** tabs and addable examples; a
  collapsible panel; a No visualization mode; scalar sliders with play and
  pause.
- **Corrections.** Outer products keep their spanning vectors whatever the
  operand syntax, inside lists and through versor sandwiches, and list
  elements derived from positioned operands inherit their position or report a
  conflict ([#85](https://github.com/eharquin/gamut/issues/85),
  [#87](https://github.com/eharquin/gamut/issues/87),
  [#88](https://github.com/eharquin/gamut/issues/88)).

## Verification status

`npm run verify` passes on the release commit: type check, lint, 50 test
files and 1002 tests, and the production build. Publishing the release deploys
its artifact to GitHub Pages.

## Known scope and limitations

- The PGA(2) acceptance criteria that need the deployed application (browser
  workflow, reload of a 0.1.0 export, accessibility checklist) remain pending
  manual validation ([#192](https://github.com/eharquin/gamut/issues/192)).
- The supported-browser matrix is the one validated for 0.1.0: current Chrome
  and Firefox on Linux and Safari 17.6 on macOS. Microsoft Edge, touch input
  (including pinch-to-zoom, [#120](https://github.com/eharquin/gamut/issues/120))
  and mobile browsers are not claimed.
- Floating-point results are shown unrounded, so rotations may display noise
  such as `2.220446049250313E-16`; per-algebra precision policies are tracked
  by [#68](https://github.com/eharquin/gamut/issues/68).
- A top-level item computed from positioned operands, such as `B = V1 ^ V2`,
  keeps its own position source and is drawn at the origin when it has none.
- Graphs are stored in the active browser or shared as files and links;
  collaborative storage, embedding ([#215](https://github.com/eharquin/gamut/issues/215))
  and figure export are not included.
