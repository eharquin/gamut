# GAMUT 0.3.0 Release Notes

- **Status:** Stable release
- **Tag:** `v0.3.0`
- **Release date:** 2026-11-20
- **Milestone:** [0.3.0](https://github.com/eharquin/gamut/milestone/4)
- **Requirements:** [Library and Expression Organization](../requirements/milestones/library-and-expression-organization.md)
- **Acceptance:** [Library and Expression Organization Acceptance Record](../acceptance/library-and-expression-organization.md)
  (automated evidence ready; manual and deployed validation pending,
  [#272](https://github.com/eharquin/gamut/issues/272))
- **Changelog:** [0.3.0](../../CHANGELOG.md#030---2026-11-20)
- **Previous release:** [0.2.0](0.2.0.md)

GAMUT 0.3.0 turns the local graph library into a library panel with folders,
shipped examples and archives, organizes the expression panel with folders and
notes, adds embed mode for presentations, and makes the coordinate tuple
owned by the active algebra. Every 0.1.0 and 0.2.0 document, scene link and
library opens unchanged.

## Highlights

- **Library panel.** **Library** opens a gallery docked on the right, 420 px
  wide by default and widened to the left from its edge, with **My library**
  (browser storage) and **Examples** (read-only scenes that **Add to my
  library** copies). Both are organized in folders, filtered by algebra and
  searched by name; each graph is a card with a drawing of its scene
  ([#266](https://github.com/eharquin/gamut/issues/266),
  [#267](https://github.com/eharquin/gamut/issues/267),
  [#328](https://github.com/eharquin/gamut/issues/328)).
- **Examples and first run.** Ten VGA(2) and PGA(2) example scenes, sorted by
  algebra and topic; the first run and the algebra switch open the algebra's
  showcase example ([#270](https://github.com/eharquin/gamut/issues/270),
  [#217](https://github.com/eharquin/gamut/issues/217)).
- **Library archives.** **Export library** downloads My library as a `.zip` of
  canonical documents in folders; **Import library**, or dropping the archive
  on the window, imports it safely into a new folder without overwriting a
  graph ([#268](https://github.com/eharquin/gamut/issues/268)).
- **Expression folders and notes.** Named, collapsible folders, created from
  the add menu or by typing `/` first, which may overwrite the appearance of
  their rows ([#83](https://github.com/eharquin/gamut/issues/83)); notes,
  created by typing `"` first, shown as Markdown with headings, lists, code
  and mathematics ([#187](https://github.com/eharquin/gamut/issues/187)); a
  **Cards** panel style.
- **Embed mode.** A scene link in an iframe, such as a Slides.com block, shows
  only the canvas, with **Open in GAMUT** and fullscreen when allowed, and
  never touches browser storage ([#215](https://github.com/eharquin/gamut/issues/215)).
- **Coordinate tuples and weighted points.** `(x, y)` is a vector in VGA(2)
  and a point in PGA(2), where `(x, y, w)` is a homogeneous point; dragging a
  weighted point keeps its weight, and dragging a tuple rewrites it in place
  ([#180](https://github.com/eharquin/gamut/issues/180),
  [#181](https://github.com/eharquin/gamut/issues/181)).
- **Labels and appearance.** Labels drawn alone or centred, angles in radians,
  a graph-wide **Expression labels** switch, values in labels with `${…}`,
  objects held in place on the canvas, opacity that fades points, and lists
  of points whose points, border and fill are drawn independently, with
  automatic labels kept out of the fill
  ([#316](https://github.com/eharquin/gamut/issues/316),
  [#317](https://github.com/eharquin/gamut/issues/317),
  [#332](https://github.com/eharquin/gamut/issues/332)).
- **Scalar sliders.** Bounds derived from the value when left empty, a
  **Speed** in the Animate menu, and a slider shown on the canvas
  ([#318](https://github.com/eharquin/gamut/issues/318)).
- **Expression rows and display.** The value follows the kind on one line, a
  **Show multivector values** setting hides the values
  ([#191](https://github.com/eharquin/gamut/issues/191)), saving stops slider
  animations ([#265](https://github.com/eharquin/gamut/issues/265)), the dark
  theme has more contrast ([#324](https://github.com/eharquin/gamut/issues/324)),
  and a **Performance monitoring** setting shows frame rate and timings over
  the canvas ([#326](https://github.com/eharquin/gamut/issues/326)).

## Compatibility

- **Canonical document format 13.** Documents move from version 7 (0.2.0)
  through versions 8 to 13: hidden values, notes, folders and their
  appearance, labels and dragging, and the fill of point lists. Earlier
  documents migrate on load and draw as before; label angles stored in
  degrees are converted to the same angle in radians. See the
  [document format](../specifications/document-format.md) history.
- **Library index.** The index keeps version 1: entries gain an optional
  `folder`, and empty folders use a separate key. 0.2.0 keeps every graph and
  its folder, except that saving a graph from 0.2.0 moves it to the root.
- **Downgrade.** 0.2.0 cannot open a document written by 0.3.0, and reloading
  0.2.0 after 0.3.0 replaces the stored active document with the example. This
  is accepted while GAMUT has no users
  ([#275](https://github.com/eharquin/gamut/issues/275)). A page of 0.3.0
  opened before a later deployment likewise refuses documents in a newer
  format until it is reloaded.
- **Language.** The language version does not change: tuples and notes only
  make valid sources that were errors before.

## Verification status

`npm run verify` passes on the release commit: type check, lint, 72 test files
and 1481 tests, and the production build. Shipped examples are tested to be in
the current canonical format and to open without diagnostics. Publishing the
release deploys its artifact to GitHub Pages.

## Known scope and limitations

- The manual checklist of the
  [acceptance record](../acceptance/library-and-expression-organization.md) on
  the supported browsers, and the deployed smoke test of the VGA and PGA
  workflows ([#274](https://github.com/eharquin/gamut/issues/274)), remain
  pending ([#272](https://github.com/eharquin/gamut/issues/272)). The 0.2.0
  PGA(2) acceptance still needs its browser versions recorded
  ([#192](https://github.com/eharquin/gamut/issues/192)).
- The supported-browser matrix is the one validated for 0.1.0: current Chrome
  and Firefox on Linux and Safari 17.6 on macOS. Microsoft Edge, touch input
  ([#120](https://github.com/eharquin/gamut/issues/120)) and mobile browsers
  are not claimed.
- The rest of the `App.tsx` split (visualizer rendering, gesture hooks and the
  document session) is not done ([#173](https://github.com/eharquin/gamut/issues/173)).
- Per-algebra numerical and display policies are not in place
  ([#68](https://github.com/eharquin/gamut/issues/68)).
- Graphs are stored in the active browser or shared as files, archives and
  links; collaborative storage and figure export are not included.
