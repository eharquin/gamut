# GAMUT 0.3.0 Scope

- **Status:** Planned
- **Milestone:** [0.3.0](https://github.com/eharquin/gamut/milestone/4)
- **Previous release:** [0.2.0](0.2.0.md)

GAMUT 0.3.0 turns the local graph library into a browsable library panel with
personal graphs and shipped examples, both in folders, adds folders and
comment rows to the expression panel, makes the coordinate tuple a PGA point,
and splits `App.tsx` before these interface additions land. It also closes the
pending acceptance of 0.2.0.

This document records the planned scope. It becomes the release notes when
0.3.0 is published.

## Design decisions

- **Coordinate tuples.** The tuple is resolved by the active algebra, never by
  a hidden `vector` call. In PGA(2), `(x, y, w)` is a homogeneous point, so
  `(x, y, 0)` is an ideal point; a triple is never a line, which keeps
  `line(a, b, c)`. No short aliases such as `p(…)` or `l(…)` are added
  ([#180](https://github.com/eharquin/gamut/issues/180)).
- **One format change for folders.** Expression folders (#83) extend the
  canonical document format, library folders (#267) extend the library index,
  and the `.zip` archive (#268) stores folders as directories. They are
  designed together, with one folder model and, where possible, one folder
  component in the interface.
- **Comment text.** Comment rows (#187) render a restricted Markdown subset —
  bold, italic, inline code and links — without raw HTML and without
  `innerHTML`, since shared scene links display text written by someone else.
  Mathematical notation is left to a later issue.
- **Interface lands outside `App.tsx`.** New panels, menus and rows are
  separate components and hooks (#173).
